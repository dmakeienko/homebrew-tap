# homebrew-tap

Personal Homebrew tap for [dmakeienko](https://github.com/dmakeienko)'s tools.

## Usage

```sh
brew tap dmakeienko/tap
brew install tfenvgo
```

## Available formulae

| Formula | Description |
| --- | --- |
| [tfenvgo](https://github.com/dmakeienko/tfenvgo) | Terraform/OpenTofu version manager written in Go |

Formulae in this tap are published automatically by [GoReleaser](https://goreleaser.com/) when a new release is tagged in the source repository. Do not edit the `Formula/*.rb` files directly — changes will be overwritten on the next release.
